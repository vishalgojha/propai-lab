# Notification sound

`notify-chime.ogg` is a short CC0 notification chime from Wikimedia Commons:

https://commons.wikimedia.org/wiki/File:Simple_Happy_Beep.ogg

Replace the file at `frontend/public/sounds/notify-chime.ogg` with another
short, pleasant royalty-free sound if desired. The app uses the same sound for
all notification categories and applies the Sound controls volume on every
playback.

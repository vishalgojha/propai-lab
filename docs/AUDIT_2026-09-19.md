  propai migrations are untracked in git (e.g. `20260906170000_listing_reports*`).

  repo (the functions live only in the project).

## 3. Security & auth

Severity-ranked findings with `file:line` references.

### CRITICAL
1. **Unauthenticated `POST /webhook`** — `routers/infra.py:1582`. No token, no
   signature, no auth. Message intake resolves tenant from `broker_id` and
   triggers the extraction pipeline. Path is outside `/api` so the rate limiter
   (`app.py:202-233`) does not apply.
2. **Entire app layer runs as `service_role` (RLS bypass)** —
   `storage/supabase.py:2331-2339,2158-2165`. Tenant isolation depends entirely
   on app-layer checks, which are incomplete (below). One authz bug = full DB access.
3. **Cross-tenant IDOR on org management** — `routers/auth_org.py:212-284`.
   GET/PATCH `/api/orgs/{id}`, member list/add/remove/role, and roles routes are
   gated only by `require_user`, with no membership or super-admin check.

### HIGH
4. **Meta WABA receivers without signature verification** —
   `routers/whatsapp_sync.py:263,279,296` accept POST bodies with no
   `X-Hub-Signature-256` validation (contrast `routers/lead_ingestion.py`).
5. **Internal token falls back to `SUPABASE_SERVICE_KEY`** —
   `routers/common.py:1286`, `routers/infra.py:1831-1834`,
   `routers/workspace.py:94-95`, `services/whatsmeow-ingestor/main.go:2122-2127`.
6. **`get_current_member` defaults to org OWNER** — `routers/common.py:494-507`
   when `x-team-member-id` header absent (or synthetic System with all perms).
   Affects `notes.py`, `workspace.py`, `send.py`.
7. **`SUPABASE_JWT_SECRET` multi-purpose** — HS256 JWT verification
   (`common.py:123,146-156`), agent/admin confirmation HMACs
   (`admin_ops.py:194`, `social_flow.py:79`, `ai_chat.py:700`, `agent_tools.py:788`),
   MCP token encryption (`services/meta_mcp_oauth.py:31-34`).
8. **Mutating admin ops take raw `dict` bodies** — `admin.py:425-465`,
   `admin_ops.py` un-typed bodies forwarded to DB writes (role-gated but no
   schema validation). Also `auth_org.py:220-229,237-246`.
9. **`is_active`/rename allowed cross-tenant** — `update_organization`
   (`auth_org.py:220-229`) can rename/deactivate any org (compounds #3).

### MEDIUM
- `/docs` + `/redoc` public (`app.py:191-192`); exception handler leaks
  `str(exc)[:500]` + traceback line (`app.py:346-354`).
- `GET /api/public/listings` returns `l.pic_token` per listing (`send.py:418`).
- Non-constant-time challenge compares — `business_api.py:182`, `whatsapp_sync.py:274`
  (constant-time variant exists at `whatsapp_sync.py:291`).
- Prompt injection via client `context` — `apps/www/src/app/api/ai-chat/route.ts:66-75`.
- Un-scoped notes lookup — `routers/notes.py:23-33`.
- Open `/api/public/leads` intake (`send.py:295-394`) — SQL parametrized, safe on injection, but a spam/abuse surface.
- Ingest event-store overlap: `whatsapp_events` live vs `whatsapp_webhook_outbox` (0) vs `webhook_outbox_archive` (0).

### LOW
- `frontend/src/app/api/admin/analytics/route.ts:4` hardcodes
  `ADMIN_EMAIL = "vishal@chaoscraftlabs.com"`; client-side admin flag
  (`frontend/src/app/layout.tsx`) is cosmetic only (backend enforces).
- `apps/www/src/lib/supabase.ts:23-25` falls back to anon key (no secret leak; brittle).
- `.api_key` file persisted at startup (`app.py:116-120`).
- Unused/retired tables kept alive because live tables FK into them:
  `listings_legacy`, `market_requirements_legacy`, `parsed_output_legacy`.

## 4. Architectural risk summary

- **Monolithic DB layer**: 12,437-line `supabase.py`; `_translate_sql` only
  rewrites `?` → `$N` placeholders — not a sanitizer. String-interpolated
  identifiers in admin/dashboard helpers (`common.py:1519,1543`, `brokers.py:252`).
- **Chariot on shared tenant**: same schema isolates nothing physically;
  untracked migrations and empty volcano tables make schema drift a two-team problem.
- **Worker/queue sprawl**: 7 polling workers + in-process scheduler; high-growth
  log tables with no retention policy (`extraction_attempt_log` 956K and growing).
- **Git hygiene**: DB state not reproducible from repo (drift above).

## 5. Priority remediation plan

1. Authenticate `POST /webhook` (internal token and/or HMAC) — `infra.py:1582`.
2. Meta signature validation on all three WABA POST receivers — `whatsapp_sync.py:263,279,296`.
3. Enforce org membership / super-admin on `auth_org.py:212-284`.
4. Drop the `SUPABASE_SERVICE_KEY` fallback for internal tokens; require
   `PROPAI_INTERNAL_TOKEN` (`common.py:1286` + mirrored sites, Go main.go).
5. Fix `get_current_member` owner-default (`common.py:498-501`).
6. Typed body models on `admin.py:425-465` / `admin_ops.py`; scope `notes.py` by tenant.
7. Review `/docs`, `/redoc`, exception handler output (`app.py:191-192,346-354`).
8. Do not return `pic_token` from `/api/public/listings` (`send.py:418`).
9. Reconcile migrations: apply/delete the ~120 drift files; commit untracked
   propai migrations (incl. `listing_reports`) and add its RLS policies.
10. Hygiene: drop 348 unused indexes, fix 7 initplan policies + 9 FK indexes,
    move `pg_net` out of public, add PK to `whatsmeow_version`; tune auth
    connections to percentage-based.
